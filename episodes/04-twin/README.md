# ④ 장비 없이 먼저 돌리는 3D 디지털 트윈

> 영상: 공개 예정 · 앞 편 [③ IronHMI 조작 화면](../03-ironhmi/) · 다음 편 [⑤ IronCAM](../05-ironcam/)

장비보다 먼저 화면에서 G코드를 돌려 보고(시뮬레이션 · 판정), 실기에서는 실제 축과 같이 움직이고(링 버퍼), 끝난 작업은 다시 재생합니다(블랙박스).

| 단계 | 파일 · 화면 |
|---|---|
| 모델 | [`src/HMI/Models/cnc_gantry.glb`](../../src/HMI/Models/) — 장비 STEP 조립도 → glb → Blender 헤드리스 정리 스크립트(부품 묶기 · 원점 자세 · 헤드 · 내보내기) |
| G코드 읽기 · 판정 | IronHMI 작업현황 › 시뮬레이션 창 — 아래 판정 항목 |
| 실기 동기 | PLC [`Motion/RingBuffer`](../../src/PLC/Logical/Motion/RingBuffer) → HMI 노드 키 `::RingBuffer:<변수>` |
| 남은 시간 · 다시 보기 | 작업현황 진행 칸, 작업이력 › 작업 재생 |
| 시험 파일 | [`gcode/TWIN_RANGE_TEST`](../../gcode/) — 일부러 범위를 벗어나는 경로 (이 편을 공개할 때 추가) |

## 노드 이름 약속

3D 모델은 노드 **이름**으로 축을 찾고, **평행 이동만** 합니다(회전 없음). 모델을 새로 만들 때 이 이름과 부모-자식 관계를 지키면 HMI 코드를 고치지 않아도 됩니다.

```
GantryY            ← 기계 X 축 (긴 베이스 레일)
 └─ GantryX        ← 기계 Y 축
     └─ GantryZ    ← 기계 Z 축
         ├─ Nozzle ← 디스펜서 노즐 끝
         └─ Laser  ← 레이저 출구 (레이저 헤드 장착 시 원점)
```

- 부품표 이름(GantryY)과 실제 축(기계 X)이 반대입니다. 현장 확인 전까지 3D 의 X·Y 가 바뀌어 움직였던 이유입니다 — 이름이 아니라 **실제로 움직이는 방향**으로 연결하세요.
- 모델 단위는 mm, 원점은 원점 복귀 자세(축 0 위치)입니다.

## 판정 항목 표

시뮬레이션 창의 판정은 아래 항목을 봅니다. 하나라도 **불합격**이면 판정이 불합격입니다.

| 항목 | 보는 것 | 결과 |
|---|---|---|
| V0 해석 완전성 | 해석기가 읽지 못한 줄 · 풀지 못한 값이 있는가 (모르는 G·M 코드는 건너뛰지 않고 남김) | 1건이라도 있으면 **불합격** |
| V1 축 범위 | 기계 좌표(프로그램 + G92)가 축 범위(X −5~450 · Y −5~430 · Z −5~145 mm) 안인가 | 벗어나면 **불합격** — 「라인 n 부근에서 축 범위 이탈」 |
| A1 헤드 켜기/끄기 | 켜기 · 끄기 코드 짝이 맞는가 | 짝이 안 맞으면 불합격, 켜기 구간이 없으면 경고 |
| V2 헤드 켜짐 속도 | 헤드가 켜진 구간의 최고 이송이 축 한계를 넘는가 | 넘으면 경고 (실기는 한계로 깎임) |
| V3 이송 높이 | 작업 높이 그대로 1 mm 넘게 수평 이송하는가 | 있으면 경고 (헤드가 끌릴 수 있음) |
| V4 헤드 켜짐 중 Z | 헤드가 켜진 채 Z 가 0.5 mm 넘게 움직이는가 | 있으면 경고 (자국 높이 불균일) |
| V5 레시피 변수 | 옛 레시피 변수를 쓰는가 (지금 PLC 에 없음 → 0 으로 계산) | 쓰면 보류 |
| V6 시작 이동 | 시작 위치 → 첫 점 거리 | 정보 |
| V7 예상 소요 | 거리 · 이송 · 가감속(2000 mm/s² 근사)으로 계산한 시간 | 정보 |

## 실기 동기 (링 버퍼)

PLC `RingBuffer` 태스크가 2 ms 마다 축 위치(`BufferX/Y/Z`) · 헤드 켜짐(`BufferHeadOn`) · 움직임(`BufferMoving`) · 레이저 출력(`BufferLaserPower`, %)을 500칸(1초) 버퍼에 적고, HMI 가 약 0.1초마다 읽어 3D 에 그립니다. 레이저 자국은 출력 1% 단위로 0% 연한 회청 → 100% 진한 남색으로 칠합니다.

## 사용 환경

IronHMI 3D 트윈 · OPC UA · B&R X20CP1684 · Blender(모델 정리) · glb
